## Story Context [ARCHIVED]

Epic 4 focuses on implementing a comprehensive power-up system that adds strategic depth to the gameplay. Story 4.3 extends the power-up system established in Stories 4.1 and 4.2 by adding advanced power-ups that provide more sophisticated gameplay mechanics: Shield/Barrier, Slow Motion, Pierce Ball, Magnet Paddle, and Laser Gun. These power-ups will integrate with the existing plugin architecture while introducing new gameplay dynamics.

**Existing System Integration:**
- Integrates with: PowerUpSystem, PowerUpPlugin base class, PowerUpRegistry
- Technology: TypeScript, Canvas API, Plugin Architecture
- Follows pattern: Existing power-up plugin pattern from MultiBallPowerUp, PaddleSizePowerUp
- Touch points: PowerUpRegistry.registerAllPowerUps(), PowerUpSystem.applyEffect(), GameState management

## Acceptance Criteria

**Functional Requirements:**
1. **AC1**: シールド/バリア実装 - Shield that blocks one ball miss
2. **AC2**: スローモーション実装 - Temporarily slows down game time (except paddle)
3. **AC3**: 貫通ボール実装 - Ball passes through blocks without bouncing
4. **AC4**: マグネットパドル実装 - Ball sticks to paddle on contact, release with click
5. **AC5**: レーザー発射実装 - Shoot projectiles from paddle to destroy blocks

**Integration Requirements:**
6. Each power-up follows existing PowerUpPlugin pattern
7. Power-ups registered through PowerUpRegistry
8. Visual indicators integrated with HUD PowerUpStatus component
9. Existing power-ups continue to work unchanged
10. Effect stacking rules properly managed for compatibility

**Quality Requirements:**
11. Unit tests for each power-up plugin
12. Integration tests for power-up combinations
13. Visual feedback for each power-up activation
14. Performance remains at 60 FPS with active effects

## Technical Notes

### Implementation Approach

**Shield/Barrier Power-Up:**
- Create `src/game/plugins/powerups/ShieldPowerUp.ts`
- Add shield state to GameState
- Visual: Semi-transparent barrier at bottom of screen
- Effect: Nullifies one ball miss, then deactivates

**Slow Motion Power-Up:**
- Create `src/game/plugins/powerups/SlowMotionPowerUp.ts`
- Modify game loop delta time (except for paddle movement)
- Visual: Time distortion effect overlay
- Duration: 10 seconds

**Pierce Ball Power-Up:**
- Create `src/game/plugins/powerups/PierceBallPowerUp.ts`
- Modify collision system to allow pass-through
- Visual: Ball trail effect
- Duration: 15 seconds or 10 blocks

**Magnet Paddle Power-Up:**
- Create `src/game/plugins/powerups/MagnetPaddlePowerUp.ts`
- Add magnetic state to paddle entity
- Interaction: Click or space to release attached ball
- Visual: Magnetic field effect around paddle

**Laser Gun Power-Up:**
- Create `src/game/plugins/powerups/LaserGunPowerUp.ts`
- Add projectile system to game
- Fire rate: 2 shots per second
- Visual: Laser beams from paddle edges
- Duration: 20 seconds

    });
  }
  
  protected applyEffect(): void {

  }

- Effects must cleanly reverse on expiration
- Compatibility with existing power-ups required

## Risk and Compatibility Check

**Primary Risk:** Performance impact from multiple simultaneous visual effects
**Mitigation:** Implement effect pooling and optimize rendering pipeline
**Rollback:** Each power-up can be disabled independently via PowerUpRegistry

**Compatibility Verification:**
- [x] No breaking changes to PowerUpPlugin base class
- [x] PowerUpRegistry remains backward compatible
- [x] Existing power-up functionality unchanged
- [x] GameState additions are optional/additive
